Albedo

浏览器里的 SVG 工作台

Albedo 把矢量编辑器打包成一个 HTML 文件：双击打开，就能画图形、改路径、整理图层，再把结果导出成干净的 SVG。不需要安装，不用登录，也没有后端。

打开编辑器 → GitHub

能做什么

features

  • 图形与路径

    矩形、椭圆、圆、多边形、直线、路径和文字；节点、控制柄都能直接拖。

  • 导入 SVG

    保留元素类型、坐标和原始标记，导入后就是普通图层，可以继续改。

  • 排版与整理

    多选、框选、移动缩放、对齐、等距分布，以及路径的布尔运算。

  • 图层与画布

    调整图层顺序和画布尺寸，打开网格、吸附，或者放一张参考图描摹。

  • 文字转轮廓

    用本机字体排版，导出时转成轮廓，别人打开不会缺字体。

  • 干净导出

    下载 SVG 文件或复制源码；界面支持简体中文和 English。

一个文件，离线可用

仓库不提交构建产物。安装依赖、构建一次，根目录就会出现 svg-editor.html：双击打开，或者直接发给别人。

推荐 Chrome：文字图层读取本机字体需要它的本地字体权限。
