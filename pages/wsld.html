wsld

给 WSL 容器一个窗口

wsld 是 wslc 的 WinUI 3 图形外壳。wslc 是 WSL 3 的容器命令行；wsld 把容器、镜像、日志和 run 命令都收进一个窗口——能点、能看，也能把命令复制走。

下载安装包 → GitHub

Windows 11 · 需要 WSL 3（wslc） · 安装包已带运行时

能做什么

features

  • 容器列表

    搜索、汇总、状态一眼看清；启动、停止、重启、删除都在手边。

  • 详情与日志

    字段卡片、历史日志、实时跟随；取消就停，不留半死的 wslc 进程。

  • 镜像管理

    按引用数排序，搜索、拉取、删除；拉取时按层显示实时进度。

  • 运行命令

    用表单拼出 wslc run，生成、复制、执行、读回输出，还留着历史。

  • 镜像加速

    把镜像源换成加速地址，拉完再改回原名，少等一会儿。

  • 主题与语言

    跟随系统、浅色或深色；简体中文和 English 随时切换。

装好就能用

下载 wsld-Setup-<版本>-x64.exe 双击安装。不用预装 .NET 或 Windows App SDK；实际使用仍需本机已装 WSL 3（含 wslc.exe）。

界面是 WinUI 3，业务逻辑在独立的 wsld.Core：进程调用、输出解析和 ViewModel 都在那里，单元测试不用碰真容器。
